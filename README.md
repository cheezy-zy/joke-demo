# joke-demo

Entry for the [make.fun](https://make.fun) competition
[the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551):
one line about working beside AI coding agents.

## Run

```bash
python main.py
```

Python 3.13, standard library only, no network.

## Output

`output/entry.txt` — one line of UTF-8 text, 1 to 280 code points. The
program is deterministic: two runs produce byte-identical files.
